# Flappy Bird Game

This is a simple implementation of the classic Flappy Bird game using HTML, CSS, and JavaScript.

## How to Play

- **Start the game:** Click the "Start Game" button.
- **Fly:** Press the `Spacebar` on your keyboard or tap the screen on a mobile device to make the bird jump.
- **Objective:** Navigate the bird through the gaps in the pipes to score points.
- **Game Over:** The game ends if the bird hits a pipe or the ground.

## Features

- **Responsive Design:** The game is playable on both desktop and mobile devices.
- **Score Tracking:** Your current score is displayed during the game.
- **Best Score:** Your highest score is saved locally in your browser and displayed on the game over screen.
- **Dynamic Background:** The game features moving clouds in the background for a more immersive experience.

## Technologies Used

- **HTML5:** For the basic structure of the game.
- **CSS3:** For styling the game elements, including the bird, pipes, and screens. Tailwind CSS is used for some utility classes.
- **JavaScript (ES6):** For the game logic, including controls, physics, and collision detection.

## File Structure

- `flappy-bird.html`: A single HTML file that contains all the necessary HTML, CSS, and JavaScript code for the game.

## How to Run

Simply open the `flappy-bird.html` file in a modern web browser.
